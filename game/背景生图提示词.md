# 《夏日幻想》背景生图提示词

> 用途：为《夏日幻想》各章节生成 WebGAL 视觉小说背景。
>
> 22 张背景已生成并接入剧本（`title_bg` 暂未启用）。本文保留按章节的背景清单、提示词和接入位置；如需重生成或补图，可直接按卡片修改。

---

## 一、快速使用

1. 先读“通用规范”，把风格锚点和负面词固定下来。
2. 按“章节背景清单”确定要生成哪些图。
3. 在“背景提示词卡片”里复制对应条目的中文或英文提示词。
4. 生成 16:9、1920×1080 的图，转成 WebP 后放进 `game/background/`。
5. 背景已经接入；如果要替换某张图，保持文件名不变即可，脚本无需再改。

建议一次只生成一个地点，用同一组风格词和相近种子，保证所有背景像同一部作品。

## 二、通用规范

### 2.1 风格锚点（每条提示词都建议带上）

**中文：**

> 日系动画视觉小说背景，干净的动画插画风格，细腻厚涂，电影感构图，柔和自然光，轻微空气透视，中国南方城市青春怀旧氛围，低饱和暖色调，高分辨率，16:9 横屏，画面中无人物，无可读文字，无水印，。

> 

### 2.2 通用负面词

**中文：**

> 人物，角色，人脸，手，文字，汉字，英文，水印，logo，UI，对话框，签名，低清晰度，模糊，透视畸变，过饱和，3D 渲染，照片写实，杂乱

**English:**

> people, characters, humans, faces, hands, text, letters, Chinese characters, watermark, logo, UI, dialogue box, signature, lowres, blurry, distorted perspective, oversaturated, 3D render, photorealistic, messy clutter

补充：

- 教室、走廊、校门、体育馆里的公告栏、横幅、倒计时牌，全部要求“字迹模糊/不可读”，不要指望模型写对中文。
- 画面中不要出现主角或任何可辨认的角色，人物由 Live2D 立绘叠加。
- 对话框大约占画面下方 27%–30%，因此下三分之一不要放重要信息。

### 2.3 参数建议

| 工具 | 建议 |
| --- | --- |
| Midjourney | `--ar 16:9 --v 6.1 --style raw --s 150` |
| Stable Diffusion / SDXL | 1920×1080，30 步，CFG 7，DPM++ 2M Karras，开启 1.5× hires fix |
| 即梦 / 可灵 / 其他中文模型 | 画面比例 16:9，风格选“动漫/插画/视觉小说背景”，高清 |
| 统一性 | 同一地点用同一个种子或同一张参考图做 img2img；只改天气/时间，不改构图 |

### 2.4 构图与留白

- 镜头高度约 1.4–1.6 米，平视，广角 24–35mm，不要鱼眼。
- 重要景物放在画面上半部或左右两侧，中间偏下留给角色立绘。
- 不要在最下方放台阶、文字、亮色物体，否则会被对话框盖住。

## 五、脚本接入示例（节选，已生效）

### 5.1 文件放置

把生成图转成 WebP，放到：

```text
game/background/
├─ classroom_day.webp
├─ classroom_rain.webp
├─ corridor_day.webp
├─ corridor_rain.webp
├─ bus_stop_rain.webp

└─ title_bg.webp
```

### 5.2 基本命令

```text
changeBg:classroom_day.webp -next;
```

`-next` 表示不等待背景转场完成就继续下一句，和现有章节开头的写法一致；具体过渡时长可在 Terre 的转场设置里调整。

### 5.3 序章示例

```text
changeBg:classroom_day.webp -next;
:初三开学第一天，班主任把新的座位表贴在了讲台上。;
...
; 序章目前不切走廊，兰屿以门口立绘表现
; 如果想补走廊镜头，可在“走廊上又探进来一个脑袋”前切 corridor_day，放学再切回
...
; 放学仍保持 classroom_day
:放学铃响的时候，乐茹把书签夹回书里，忽然问我。;
```

### 5.4 第一章雨天示例

```text
changeBg:classroom_rain.webp -next;
:周一放学，天忽然阴下来。;
pixiInit;
pixiPerform:rain;
...
label:d2_give
:我把伞塞进她手里。;
...
changeBg:corridor_rain.webp -next;
:她撑着伞站在走廊尽头。;
...
```

如果继续使用 `pixiPerform:rain`，背景只要画“阴天/湿玻璃”，不必再画很重的雨丝，否则会和引擎雨效叠成双层。

### 5.5 第二章分支示例

```text

...

changeBg:mountain_trail.webp -next;

changeBg:mountain_summit.webp -next;
:山顶的风很大。;
...
label:saturday_game
...
:她隔了很久才回：好。;
changeBg:netcafe.webp -next;
:第二天，网吧里烟雾缭绕。;
```

### 5.6 第七章与结局示例

```text

:初三来得比想象中快。;
...

changeBg:library.webp -next;
:从那天起，每周三放学，我们都会去图书馆。;
...

:放榜那天，我一个人去了学校。;
```

```text
; end_good.txt
changeBg:school_gate_summer.webp -next;
; end_bad.txt
changeBg:corridor_winter.webp -next;
```

### 5.7 注意事项

- 同一场景里不要频繁 `changeBg`，一般一个情绪段落换一次。
- 分支标签开头换背景最安全，避免在 `choose` 中间切换。
- 换背景前先确认该分支后面没有依赖上一张背景的台词。
- 新背景全部放入 `game/background/`，文件名用英文小写和下划线，避免 URL 编码问题。
- 如果暂时不想改脚本，只生成图片，也可以先作为素材库保留。
